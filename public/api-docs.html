Yenllet API Docs

Introduction

Welcome to the Yenllet VTU API. You can use our API to integrate Airtime, Data, Electricity, and TV subscription services directly into your own applications.

Base URL: https://yenllet.name.ng/api/v1

Authentication & API Key

All API requests require your secret API key. You must include it in the headers of every request.

How to get your API Key:

  • Login to your Yenllet Dashboard.
  • Navigate to Profile -> Developer API Key.
  • Click "Generate New Key".
  • Copy the generated key. It will look like yl_xxxxxxxx...
headers: {
  "x-api-key": "yl_your_api_key_here",
  "Content-Type": "application/json"
}

How Transactions Work

When you make a purchase request (e.g., Buy Data), the following happens:

  • The API deducts the exact selling price from your Yenllet wallet balance.
  • The API routes the request to the network provider (e.g., MTN, DSTV).
  • If successful, it returns a success response with the Transaction ID.
  • If it fails, the funds are automatically refunded to your Yenllet wallet.
  • Note: A 4-digit Transaction PIN is required for all purchase endpoints to authorize the deduction from your wallet.

Code Examples

Choose your preferred programming language to see how to implement the API.

POST /airtime
const fetch = require('node-fetch');

async function buyAirtime() {
  const url = 'https://yenllet.name.ng/api/v1/airtime';
  const response = await fetch(url, {
    method: 'POST',
    headers: {
      'x-api-key': 'yl_your_api_key_here',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      provider: 'mtn',
      phone: '08012345678',
      amount: 500,
      pin: '1234' // Your Yenllet Transaction PIN
    })
  });
  const data = await response.json();
  console.log(data);
}

buyAirtime();
POST /data

Create a Next.js API Route (e.g., app/api/buy-data/route.js) to securely call Yenllet from your backend.

import { NextResponse } from 'next/server';

export async function POST(request) {
  const body = await request.json();
  
  const res = await fetch('https://yenllet.name.ng/api/v1/data', {
    method: 'POST',
    headers: {
      'x-api-key': process.env.YENLLET_API_KEY, // Store in .env
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      provider: body.provider,
      phone: body.phone,
      plan: body.plan,
      pin: body.pin
    })
  });
  
  const data = await res.json();
  return NextResponse.json(data);
}

POST /data
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class YenlletAPI {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        String jsonPayload = "{\"provider\":\"mtn\",\"phone\":\"08012345678\",\"plan\":\"1GB\",\"pin\":\"1234\"}";

        HttpRequest request = HttpRequest.newBuilder()
            .uri(new URI("https://yenllet.name.ng/api/v1/data"))
            .header("x-api-key", "yl_your_api_key_here")
            .header("Content-Type", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(jsonPayload))
            .build();

        HttpResponse response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println(response.body());
    }
}

Endpoints Reference

1. Check Wallet Balance

GET /balance

Returns the current wallet balance of the API key owner.

2. Buy Airtime

POST /airtime

Body Parameters: provider (mtn, airtel, glo, 9mobile), phone, amount, pin.

3. Buy Data

POST /data

Body Parameters: provider, phone, plan (e.g., "1GB"), pin.
