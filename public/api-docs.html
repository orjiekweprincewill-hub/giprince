Yenllet API Documentation

Integrate airtime top-up, data bundles, electricity bills, cable TV subscriptions, betting wallet funding, and education pins into your own applications. Fast, secure, and reliable — powered by Flutterwave, ClubKonnect, and CheckMyNinBvn.

Base URL: https://yenllet.name.ng/api/v1

Authentication

All API requests require a valid Yenllet API key. Include it in the x-api-key header of every request.

Two types of API keys:
  • User API Key — yl_xxxxxxxx — Generated from Profile → Developer API Key. Uses standard pricing.
  • Reseller API Key — ylrsk_xxxxxxxx — Generated from Profile → Reseller Program → Generate API Key. Uses discounted reseller pricing (requires active reseller subscription).

Headers for every request:

headers: {
  "x-api-key": "yl_your_api_key_here",
  "Content-Type": "application/json"
}

Getting Your API Key

User API Key (Standard)

  1. Create a free account at yenllet.name.ng/register.html
  2. Log in and go to Profile → Developer API Key
  3. Click "Generate New Key"
  4. Copy the generated key — it looks like yl_a1b2c3d4e5f6...

Reseller API Key (Discounted)

  1. Subscribe to the Reseller Program (₦5,000/month) from your dashboard
  2. Go to Profile → Reseller Program → Generate API Key
  3. Copy the generated key — it looks like ylrsk_a1b2c3d4e5f6...
  4. Reseller keys get the discount percentage applied to all purchases automatically
Important: Keep your API key secret. Never expose it in client-side code. Always use a backend server to make API calls. If your key is compromised, delete it immediately from your dashboard and generate a new one.

How Transactions Work

When you make a purchase request via the API (e.g., Buy Data), the following steps happen:

  1. The API deducts the exact selling price from your Yenllet wallet balance
  2. If you're a reseller, the discount is automatically applied before deduction
  3. The API routes the request to the network provider (ClubKonnect)
  4. If successful, it returns a success response with the Transaction ID
  5. If the provider fails, the funds are automatically refunded to your wallet
  6. You receive an email receipt for every successful transaction
Required: A 4-digit Transaction PIN is required for all purchase endpoints. This is the same PIN you set in your Yenllet dashboard (Profile → Transaction PIN). If you haven't set a PIN yet, do so before using the API.

Next.js API Route (app/api/buy-data/route.js)

import { NextResponse } from 'next/server';

export async function POST(request) {
  const body = await request.json();

  const res = await fetch('https://yenllet.name.ng/api/v1/data', {
    method: 'POST',
    headers: {
      'x-api-key': process.env.YENLLET_API_KEY, // Store in .env
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      provider: body.provider,
      phone: body.phone,
      plan: body.plan,
      pin: body.pin
    })
  });

  const data = await res.json();
  return NextResponse.json(data);
}

Error Codes & Handling

All errors return a JSON response with success: false and an error message.

HTTP StatusError MessageWhat to do
400Missing required fieldsCheck that all required parameters are included in the request body
400Insufficient wallet balanceFund your Yenllet wallet via card or bank transfer
400Invalid PINUse the correct 4-digit transaction PIN from your dashboard
401Missing API keyAdd x-api-key header to your request
401Invalid or inactive API keyGenerate a new API key from your dashboard
403Account is bannedContact Yenllet support
403Reseller subscription requiredSubscribe to the Reseller Program first
502Service provider errorThe network provider (ClubKonnect) failed. Funds are auto-refunded. Retry the transaction.
500Server errorTry again. If persistent, contact support.
Auto-Refund: If a transaction fails due to a provider error (502), the deducted amount is automatically refunded to your Yenllet wallet. No manual refund request needed.

Webhooks

Yenllet sends webhooks for async transaction updates. When a transaction that was "pending" is later completed or failed by the provider, Yenllet sends a POST request to your configured callback URL.

Webhook Payload (POST body):

{
  "orderid": "TXN1234567890ABC",
  "statuscode": "200",
  "orderstatus": "ORDER_COMPLETED"
}
FieldDescription
orderidThe transaction ID returned in the original purchase response
statuscode200 = completed, 100 = still processing, other = failed
orderstatusHuman-readable status: ORDER_COMPLETED, ORDER_RECEIVED
Your webhook endpoint should:
  • Return HTTP 200 immediately (don't keep the request waiting)
  • Verify the orderid matches a transaction you initiated
  • Update your database with the new status
  • If statuscode is not 200/100, refund the user on your platform

FAQ

Do I need to verify BVN to use the API?

No. BVN/NIN verification is only required to generate a virtual bank account number. The API works with just an API key and transaction PIN.

How do I fund my wallet for API usage?

Log in to your Yenllet dashboard and fund your wallet via:

  • Debit card (Visa, Mastercard, Verve) — minimum ₦100
  • Bank transfer to your dedicated Sterling Bank virtual account (requires BVN verification)
  • USSD — select Flutterwave USSD option

What happens if a transaction fails?

If the provider (ClubKonnect) returns a failure, the deducted amount is automatically refunded to your Yenllet wallet within seconds. You'll receive a 502 error response with the provider's error message.

Can I use the same API key for multiple applications?

Yes. You can use the same API key across multiple applications. However, for security, we recommend generating separate keys for each application (especially for resellers).

Is there a test/sandbox mode?

Currently, Yenllet API is in production mode only. All transactions are real. We recommend testing with small amounts (₦100) before deploying to production.

How do I get the exact plan names for data purchases?

Call GET /api/v1/plans to get all available plans with their exact names. Use the plan field value in your POST /api/v1/data request.

Can I integrate Yenllet into my existing website?

Yes! The Yenllet API is designed for exactly this. Build a VTU website, a bills payment portal, or add airtime/data purchase to your existing platform using our REST API.

Who built Yenllet?

Yenllet was founded by Orjiekwe Princewill Chigozie and is a Gustmii company. It's built on Flutterwave (payments), ClubKonnect (VTU), CheckMyNinBvn (identity verification), and Resend (email receipts).
